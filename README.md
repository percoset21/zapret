# 1337 / NIGHT — THE SIGNAL (Version 2)

Кинематографичный мини-хоррор-сайт: обратный отсчёт, анимированное приближение стилизованного монстра, лёгкие экранные помехи и короткий синтезированный звук. Без крови и жестоких сцен. На устройствах с включённой настройкой `prefers-reduced-motion` анимация сводится к минимуму.

## Публикация на GitHub Pages

1. Открой GitHub и создай новый **Public** репозиторий, например `1337-scare`.
2. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js` и `README.md`.
3. Нажми **Commit changes**.
4. Перейди в **Settings → Pages**.
5. В **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
7. После публикации сайт появится по адресу `https://ТВОЙ-НИК.github.io/1337-scare/`.

Подробная инструкция GitHub Pages: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Примечание

Аудио генерируется в браузере и запускается только после нажатия пользователем кнопки. Если браузер блокирует звук, визуальная часть всё равно работает. Используй эффект только с людьми, которые согласны участвовать.

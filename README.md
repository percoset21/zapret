# DON'T LOOK AWAY — мини-сайт со скримером

Статический сайт для GitHub Pages. Вымышленный стилизованный скример без крови и жестоких сцен. Короткий синтезированный звук запускается только после нажатия кнопки «Начать тест».

## Публикация на GitHub Pages

1. Создай новый **Public** репозиторий, например `1337-scare`.
2. Загрузи в корень репозитория `index.html`, `style.css`, `script.js` и `README.md`.
3. Нажми **Commit changes**.
4. Открой **Settings → Pages**.
5. В **Build and deployment** выбери **Deploy from a branch**.
6. Выбери ветку `main` и папку `/(root)`, затем нажми **Save**.
7. После публикации сайт будет доступен по адресу `https://ТВОЙ-НИК.github.io/1337-scare/`.

Инструкция GitHub: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

Звук можно не включать: скример также работает визуально. Не используй сайт, чтобы пугать людей, которые не согласились участвовать.
